# Rjay Solamo · Developer portfolio

A portfolio for Rjay Solamo, Web3 Engineer / Blockchain Builder. Application logic and style definitions use Rust: Leptos 0.8 server-side rendering and WebAssembly hydration, Axum, Tokio, and Serde. HTML and CSS generated from Rust provide browser presentation. The existing architecture is retained from the official [leptos-rs/start-axum](https://github.com/leptos-rs/start-axum) starter. No CSS framework, database, API credentials, handwritten JavaScript, or Node toolchain is needed. The browser loader JavaScript is generated by Leptos.

## Local setup

Install Rust using [rustup](https://rustup.rs), then from this directory:

The package uses **Rust Edition 2024**, the latest stable edition listed in the [Cargo reference](https://doc.rust-lang.org/cargo/reference/manifest.html#the-edition-field). It was stabilized in [Rust 1.85.0](https://doc.rust-lang.org/edition-guide/rust-2024/index.html). The compiler remains pinned to **1.99.1** in `rust-toolchain.toml`; the full dependency graph is verified with that compiler, not with the edition's original minimum compiler.

```bash
rustup toolchain install 1.99.1 --profile minimal --component rustfmt,clippy --target wasm32-unknown-unknown
cargo install cargo-leptos --version 0.3.11 --locked
cargo leptos watch
```

Open http://localhost:3000. The server listens on `0.0.0.0:3000`; hot reload uses port 3001. Linux needs a C linker (Ubuntu: `sudo apt-get install build-essential pkg-config`). First builds download crates and cargo-leptos build helpers and take several minutes. Keep `Cargo.lock` for reproducible dependencies. System sans-serif and monospace fonts avoid remote font requests. No provider APIs are called.

### Error handling

Server startup and origin validation use `anyhow::Result` with context for configuration, URI parsing, socket binding, and server failures. `anyhow` is enabled only for SSR; browser bindings retain their `JsValue` errors and report safe diagnostics when optional APIs are unavailable. Existing Axum/Leptos response types and the 404 page remain intact. Startup diagnostics go to the server process, never into HTTP responses. No live GitHub or RPC requests are made.

An unset `SITE_ORIGIN` retains `http://localhost:3000`. A configured origin must contain valid Unicode and be an HTTP(S) origin without paths, queries, fragments, or credentials; invalid values stop startup with an error that does not repeat the configured value. Trailing slashes are normalized. Invalid-Unicode values previously fell back to the local default; they now fail explicitly. Fragments are rejected explicitly because the HTTP URI parser otherwise discards them during validation.

## Production Linux deployment

Build on a Linux machine compatible with your server architecture and libc:

```bash
cargo leptos build --release --cargo-locked
mkdir -p deploy/target
cp target/release/rjay-portfolio deploy/
cp -R target/site deploy/target/site
cd deploy
LEPTOS_SITE_ADDR=127.0.0.1:3000 \
LEPTOS_SITE_ROOT=target/site \
LEPTOS_ENV=PROD \
SITE_ORIGIN=https://portfolio.your-domain.com \
./rjay-portfolio
```

Replace the example hostname with your domain. Run from the deployment directory, keeping the generated `target/site/pkg` files together with the binary. Axum serves those CSS, WASM, generated JS, and public assets. Do not serve `src`, `.git`, or configuration secrets. No environment variables contain secrets in this version. `.env` files are ignored, and this application does not automatically load them.

Run the binary under systemd (set `WorkingDirectory`, the four environment values above, `ExecStart`, an unprivileged user, and `Restart=on-failure`). Expose only the reverse proxy, not the Rust server port. Example Caddy configuration with automatic HTTPS:

```caddyfile
portfolio.your-domain.com {
    encode zstd gzip
    reverse_proxy 127.0.0.1:3000
}
```

Point DNS at your server, open ports 80 and 443, and let Caddy provision TLS. Verify the public homepage, `/robots.txt`, `/sitemap.xml`, unknown-route 404, asset loading, and mobile menu hydration after deployment. Use conservative caching for HTML; rebuild and deploy the binary and assets together. The default build does not fingerprint asset names, so do not apply immutable caching across releases.

This build starts a persistent Rust server. Container hosts or a Linux VPS can run it with suitable build and runtime configuration. Vercel's Rust Functions runtime requires a separate adapter and routing/build configuration; this repository has not been adapted or verified there. Static-only hosting cannot run the current SSR binary. No public deployment has been performed by this task. HTTPS and DNS require your actual server and domain.

## Editing styles in Rust

Edit the ordered `RULES` data in `src/design.rs`. Properties are Rust enum variants, values use browser CSS syntax, and `group` preserves media queries, feature queries and keyframes. For example:

```rust
rule(".container", &[(MaxWidth, "1240px"), (MarginInline, "auto")]),
group("@media (max-width: 760px)", &[
    rule(".projects", &[(GridTemplateColumns, "1fr")]),
]),
```

The small local serializer produces CSS at build time without a styling library, runtime injection, or a Node build tool. Keep declaration/rule order intact because it controls the browser cascade. Add new properties to `Property` and its name mapping as needed. This module is compiled by the Cargo build script, not included in the WASM application. Ordinary `cargo build` and `cargo leptos build` both run the generator; no separate generation command is required. Rust changes require recompilation rather than stylesheet-only hot replacement.

The generated stylesheet is embedded in the server binary, so it is always deployed with the corresponding Rust application. The public path remains `/pkg/rjay-portfolio.css`, with a build-generated content version in its query string to prevent stale browser styles after deployment. The response also requires cache revalidation. No separate generated CSS file needs copying into `target/site`. Cargo-leptos may emit an empty CSS placeholder; the explicit Axum route serves the embedded stylesheet regardless of that file. Deploy the binary and current WASM/public assets together. The existing `Stylesheet` component, CSS animation clock, SVG presentation attributes, and browser stylesheet processing remain intentional parts of the architecture.
